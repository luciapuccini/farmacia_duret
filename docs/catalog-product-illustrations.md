# Catalog product illustrations

## Provenance and use

This set was generated with OpenAI built-in image generation on 2026-09-13. It contains original raster illustrations for the Farmacia Duret catalog.

The art direction is friendly and pharmacy-focused. It uses a blue-and-mint-compatible palette, a consistent composition, soft lighting, a simple background, and a 3:2 crop. The generated masters are 1536 × 1024 pixels. The catalog uses optimized 960 × 640 WebP files.

The images are brand-neutral illustrations. Use them only to suggest a product type. The product name is the authoritative identifier. The images do not describe exact packaging, availability, dosage, prescription information, efficacy, or medical claims.

Review each image for accidental text, logos, trademarks, recognizable packaging, trade dress, medical claims, distorted objects, and inconsistent treatment. Human review must also confirm that nearby product types stay distinct.

The complete set received human visual approval on 2026-09-13.
